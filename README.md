• Sales Data Cleaning & Transformation – Excel Power Query
• Project Overview

This project focuses on cleaning, transforming, and preparing raw sales data using **Microsoft Excel Power Query**.

The raw sales data contains information about customers, cities, products, dates, quantities, and sales.

Power Query was used to perform data cleaning and transformation tasks and create an analyst-ready dataset for further analysis.

•  Tools Used

* Microsoft Excel
* Power Query

•  Dataset Columns

* Customer
* City
* Product
* Date
* Quantity
* Sales

 •  Project Objective

The main objective of this project is to clean and transform raw sales data using Excel Power Query.

The project aims to:

* Remove and handle data quality issues.
* Convert columns into appropriate data types.
* Transform text and date fields.
* Create calculated columns for analysis.
* Categorize sales based on conditions.
* Validate the final dataset.
* Create a refreshable and analyst-ready dataset.

• Data Cleaning & Transformation

The following data cleaning and transformation techniques were performed using Power Query:

• Data Cleaning

* Checked for missing values and blank rows.
* Checked for duplicate transactions.
* Applied Trim and Clean transformations.
* Converted columns to appropriate data types.
* Converted the Date column from text to Date format.

•  Text Transformation

* Split Customer Name into First Name and Last Name.
* Applied Capitalize Each Word where required.

•  Date Transformation

* Extracted Month Name from the Date column.
* Prepared the date data for further analysis.

•  Calculated Columns

* Created Sales per Unit using Quantity and Sales.
* Created Sales Category using conditional rules.
* Created Commission using a conditional calculation.

•  Data Validation

The final dataset was validated after all cleaning and transformation steps.

* Total records: 36
* Date column converted to Date format.
* Quantity and Sales columns validated as numeric values.
* Error values were checked.
* Blank rows were checked.
* Duplicate transactions were checked.
* Final dataset was reviewed before loading it back into Excel.

•  Refresh Test

A source Sales value was changed in the original Excel data and the Power Query was refreshed using **Refresh All**.

The updated value appeared in the final output, confirming that the Power Query workflow can be refreshed when the source data changes.
